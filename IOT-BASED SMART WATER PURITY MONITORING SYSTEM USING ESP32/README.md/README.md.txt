# The Invisible Threat in Drinking Water

## Problem Statement
Currently, most households and industries test water quality manually using lab methods or handheld meters, which are slow and non-continuous. People consume borewell or tap water without knowing if the TDS level has suddenly spiked beyond safe drinking limits, leading to long-term health issues like kidney stones and gastrointestinal diseases.

## Solution
An automated, real-time Total Dissolved Solids (TDS) and water quality monitoring system that alerts users immediately before unsafe water is consumed.

## Features
- Continuous real-time water monitoring.
- Instant alerts for high TDS spikes.
- Helps prevent water-borne and kidney-related health issues.
